# ひとことドライブ

スマホ向けのタクシー・観光案内英会話アプリ。30日分の構文を1日100回、声に出して練習します。

## 起動

`npm start` で起動し、 http://localhost:5173 を開きます。外部ライブラリやビルドは不要です。公開する場合は `dist` を静的サイトとして配置してください。

- DAY 1・2はユーザー指定の習得済み構文（初期値100回）です。
- DAY 3〜14は提供された教材を収録しています。
- DAY 15〜30は新たに作成した教材です。
- 回数と選択日はブラウザのlocalStorageに保存。端末間の同期はなく、ブラウザデータを消すと初期化されます。
- お手本は同梱のWAVファイルを再生します（macOS Samantha、165 words/minで生成）。ブラウザの音声選択には依存しません。
- マイクで声の大きさと無音区間を判定し、自動カウントできます。発音・文章の正誤は判定しません。音声の録音や送信は行いません。
- 開始後の1秒は静かにして周囲の音を測定。短い切れ目を許容した180ms以上の発声を1回として数え、無音が0.8秒続くと次の発話を受け付けます。
- マイクは停止、100回到達、日付変更、一覧表示、お手本再生、画面非表示時に終了します。マイク機能はHTTPSまたはlocalhostが必要です。
- お手本は全30日同じ固定音声・速度で再生します。
- Gitのプッシュ先: https://github.com/xyz201xx-dotcom/study-english.git

## 検証

`npm test` で構文数・カウント上限・保存後の再読込などを検証します。

## 公開

GitHub Pagesで `dist` を公開します。`main` へのプッシュ後、GitHub Actionsがテストを実行してデプロイします。
